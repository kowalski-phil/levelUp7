# Vokabeln aus Fotos

Protokoll von `/vokabeln-aus-foto` (wird an Tag 2 für zwei Sprachen umgebaut). Fotos liegen lokal, nicht im Repo:
- Englisch: `assets/buecher/englisch/vokabeln/Unit<n>_S<Seite>.jpg` → `content/englisch/EV.json`
- Französisch Band 2: `assets/buecher/franzoesisch/vokabeln/Unite<n>_S<Seite>.jpg` → `content/franzoesisch/FV.json` (FV.1 bis FV.7)
- Französisch Band 1: `assets/buecher/franzoesisch-band1/vokabeln/Unite<n>_S<Seite>.jpg` → `content/franzoesisch/FV.json` (FV.0)
